CANDADO 06

🔄 Compresión Dinámica

Si un nivel no califica, su comisión sube al siguiente nivel calificado

Sin compresión:   L1 ✅ → L2 ❌ (se pierde) → L3 ✅
Con compresión:   L1 ✅ → L2 ❌ (skip) → L3 ✅ (cobra L2 + L3)
💡 Ejemplo
L2 no califica (no tiene inversión suficiente). En vez de perder esa comisión, L3 la recibe junto con la suya. Las comisiones siempre se distribuyen a usuarios calificados.
